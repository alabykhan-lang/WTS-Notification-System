1

Create a sandbox key

In Bahasha, open Settings → API Keys → Create key and choose Sandbox. Copy the key when it is shown.

Open Bahasha dashboard
2

Add two Vercel secrets

In the WTS Notification System project, add these environment variables for Preview first:

BAHASHA_API_KEY = bh_test_…BAHASHA_PHONE_NUMBER_ID = your connected number ID

Redeploy after saving them. Never paste the key into source code.

3

Approve the school templates

Create these templates in Bahasha so each WTS message type has a predictable route:

wts_parent_noticewts_attendance_noticewts_fee_noticewts_result_noticewts_emergency_notice

Use named body variables such as parent_name, student_name, and message.

4

Register the webhook

Add this URL under Bahasha Settings → Webhooks:

https://wts-notification-system.vercel.app/api/bahasha-webhook

Create a private verification token, save it in Vercel as BAHASHA_WEBHOOK_VERIFY_TOKEN, and enter the same value in Bahasha.
